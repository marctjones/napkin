napkin: third-party notices for the MLX bridge in this folder
(macOS on Apple silicon only; docs/design/mlx-runtime.md in napkin's source)

This folder holds napkin's MLX bridge, which runs the assistant's model inside napkin:

  libNapkinMlx.dylib               napkin's bridge, with the libraries below compiled in
  mlx.metallib                     MLX's Metal kernels
  libswiftCompatibilitySpan.dylib  the Swift runtime's Span back-deployment library, as
                                   Apple ships it in Xcode (it is Apple-signed); macOS 26
                                   and later have their own copy and do not load this one

napkin's own bridge code (native/NapkinMlx in napkin's source) is licensed under the GNU
Affero General Public License v3.0, like the rest of napkin: see LICENSE and SOURCE.txt
beside the napkin executable.

The third-party software below keeps its own licence. Each component is listed with the
version napkin pins, its copyright notice and its licence; the licence texts follow, each
copied verbatim from the component's own licence file at that version (read 2026-09-27).
docs/third-party-notices.md in napkin's source lists the same components with links.
